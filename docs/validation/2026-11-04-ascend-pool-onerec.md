## 已验证结果

- **映射与健康：** 映射相关调用及 finalize 均成功；4096 字节真实张量读写一致，完成事件已确认、上下文恢复、释放一次。
- **小池生命周期：** `tests/pool/test_pool_ascend_realcard.py` 的三个精确用例均通过，`3 passed`、`0 skipped`：真实张量与跨流依赖、完成后复用并拒绝旧租约、观察到借用流未完成时保护原存储并在完成后复用。退出断言要求销毁完成，无 pending/quarantined/leaked，底层 live bytes 为零且申请/释放次数相等。
- **真实模型输入消费：** `tests/pool/test_onerec_inputs_ascend.py::test_onerec_forward_consumes_pool_input_ids` 为 `1 passed`。普通输入与池输入各一次 forward，batch 1、`input_ids` 形状 `[1, 19]`、int64 有效输入 152 字节，输入值相同。embedding 入口实际检查池底座的同一存储、偏移及有效范围，不以复制张量替代消费证明。关闭 cache，未运行 generate、训练或服务。
- **数值对照：** 最后一个 token 的完整 logits 向量最大绝对差为 `0.0`，argmax 相同；比较容差 `atol=rtol=0.001`。该结果不代表推荐质量或业务准确率。
- **复用与释放：** 模型输入的两个租约均确认完成后归还、排空；新租约复用同一底层存储。池底座累计申请一次 8 MiB、释放一次，live bytes 为零；销毁 completed，pending/quarantined/leaked 均为空。
- **退出观测：** 自有容器清理及移除确认成功，目标健康、无进程；最终 HBM 比初始观察值增加 2 MiB，低于 64 MiB 观察容差。模型容器有效设备规则已现场读回，仅目标计算设备有计算读写授权。
